# Escape the Box

A small game for practising rearranging equations. *x* is wrapped in layers of operations; the player peels them off from the outside in, doing the same thing to both sides.

- **Escape**: random puzzles, four difficulty tiers, par scoring
- **Build**: wrap your own equation, then escape it
- **Spot it**: find the mistake in a worked solution
- **Bosses**: real formulas (Ohm's law, F = ma, speed, y = mx + c, perimeter, °F→°C, circle area)

Plain HTML, no build step. Progress is stored in the browser on each device. Installable to a home screen and works offline.
